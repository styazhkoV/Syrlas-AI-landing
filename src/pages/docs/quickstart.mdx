# Быстрый старт с Syrlas AI

Syrlas AI Desktop Engine поставляется как локальный сервис `.NET 8`, работающий строго на локальном интерфейсе `127.0.0.1:5000`.

### 1. Проверка доступности локального контура

Перед запуском убедитесь, что порт `5000` свободен, и выполните тестовый cURL-запрос:

```bash
curl [http://127.0.0.1:5000/v1/models](http://127.0.0.1:5000/v1/models)
