# Быстрый старт с Syrlas AI

1. Реализовано на данный момент

Контур безопасности (CTI): C#-служба NetworkGuardService с перехватом событий и логикой режима Air-Gap.

Real-time Мост: SignalR Хаб (CtiMonitoringHub) для трансляции событий безопасности в реальном времени.

REST API: Контроллер CtiController (/status, /logs, /airgap).

Интерфейс: Переключение между чатом и CTI-монитором (App.tsx, Sidebar.tsx), отображение метрик и таблицы сетевых логов (CtiDashboard.tsx).


2. Осталось реализовать (Roadmap по ТЗ)

 Блок A: RAG-пайплайн и обработка документов
Парсеры файлов (.NET Backend):

Извлечение текста из документов PDF, Word (.docx), Excel (.xlsx).

Подключение OCR-модуля для распознавания текста со сканов и изображений.

Векторный индекс и Хранилище:

Настройка SQLite (с полнотекстовым поиском FTS5 или векторным расширением) для хранения фрагментов текста (чанков) и их векторов.

Интеграция с RagPanel.tsx:

Эндпоинты загрузки файлов (POST /api/rag/upload) и отслеживания статуса индексации в UI.

Блок B: Инференс локальной LLM & Потоковый ответ
C# LLM Engine:

Подключение локального рантайма (например, LLamaSharp / llama.cpp) для выполнения модели Qwen 2.5 (GGUF).

Streaming API (SSE или SignalR):

Передача сгенерированного ответа нейросети «по токенам» (token streaming) в реальном времени в компонент ChatArea.tsx.

RAG Context Assembly:

Автоматическая сборка промпта: запрос пользователя + релевантные контексты из SQLite.

Блок C: Сессии и Управление Диалогами
Персистентность истории:

Сохранение истории сообщений и чат-сессий в SQLite.

Интеграция сайдбара:

Эндпоинты /api/chat/sessions для создания, переключения и удаления диалогов из списков в Sidebar.tsx.

Блок D: Локализация (i18n)
Мультиязычный UI:

Подключение react-i18next для переключения интерфейса на 3 языка: казахский (KK), русский (RU) и английский (EN).

Блок E: Сборка и упаковка в Electron
Управление процессами (IPC):

Автоматический запуск компилированного .NET бинарника как фонового сервиса при запуске Electron.
